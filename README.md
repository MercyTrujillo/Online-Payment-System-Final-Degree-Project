# ONLINE PAYMENT SYSTEM FINAL DEGREE PROJECT

## Overview
Designed and developed a full-stack online payment system that simulates real-world payment workflows, including transaction processing, frontend interaction, and cloud deployment.

## Key Features
Payment processing workflows
Transaction handling and data persistence
Interactive frontend for user operations
REST API integration between frontend and backend
Cloud deployment with containerization
Architecture


## This project follows a full-stack architecture

Frontend: User interface built with HTML, CSS, and JavaScript
Backend: REST APIs developed using Python and Flask
Database: MySQL for data storage and transaction management
Deployment: Docker containers deployed on AWS EC2

## Tech Stack
Backend: Python, Flask, REST APIs
Frontend: HTML, CSS, JavaScript
Database: MySQL
DevOps / Cloud: Docker, AWS EC2


## System Workflow
User interacts with the frontend (payment form / UI)
Frontend sends requests to backend REST APIs
Backend processes payment logic and validations
Data is stored and managed in MySQL
Response is returned to the frontend (confirmation / receipt)

## Deployment
The application was containerized using Docker and deployed on AWS EC2, enabling a scalable and cloud-based environment.

## What I Learned
Designing full-stack applications end-to-end
Building and structuring REST APIs
Managing relational databases with MySQL
Containerizing applications using Docker
Deploying applications in cloud environments (AWS EC2)

## Summary
This project represents a complete end-to-end payment system, integrating backend services, frontend interface, database management, and cloud deployment, similar to real-world payment platforms.
